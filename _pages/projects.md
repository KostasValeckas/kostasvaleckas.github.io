### PyLongslit

**Description**: PyLongslit is a simple manual Python pipeline for processing of astronomical long-slit spectra recorded with CCD detectors. PyLongslit has been used in several research projects and publications, including the analysis of long-slit spectra from various telescopes and instruments. It has also been adopted by other researchers in the field for their own data reduction needs. Furthermore, it has been used in several BSc and MSc theses, as well as in the training of students and researchers in the field of astronomy. I have presented this software at the [Nordic-Baltic Astronomy Days](https://indico.global/event/15138/contributions/148190/).


**My Contribution**: I am the lead designer, developer and maintainer of this project. 

**Website**: <https://kostasvaleckas.github.io/PyLongslit/index.html>

**Paper**: [Valeckas et al., (2025). PyLongslit: a simple manual Python pipeline for processing of astronomical long-slit spectra recorded with CCD detectors. Journal of Open Source Software, 10(116), 9264](https://joss.theoj.org/papers/10.21105/joss.09264)

**Code**: <https://github.com/KostasValeckas/PyLongslit>

### NTE Spectrograph Data Reduction Pipeline

**Description**: This project is based on implementing the support for the 3-arm [NTE spectrograph](https://nbi.ku.dk/english/research/astrophysics/nte/) into the [PypeIt Python package](https://pypeit.readthedocs.io/en/stable/). This project utilizes simulated data to test and validate the data reduction pipeline, and to provide feedback on the optical design of the spectrograph by utilizing the Zemax model of the instrument. I have presented this project at [SPIE Telescopes+ Instrumentation 2026 conference](https://spie.org/astronomical-telescopes-instrumentation/presentation/Introducing-the-data-reduction-pipeline-for-the-Nordic-Optical-Telescope/14155-15).

**My Contribution**: I have worked on this project together with Arthur M. Kadela (equal contribution).

**Paper**: Valeckas, Kostas, Kadela, Arthur M., Viuho, Joonas K. M., Christensen, Lise B., Fynbo, Johan P. U.,
Andersen, Michael I., Sørensen, Anton N., Milvang-Jensen, Bo, and Heintz, Kasper E., “Introducing the
data-reduction pipeline for the Nordic Optical Telescope Transient Explorer spectrograph,” in [Software and
Cyberinfrastructure for Astronomy IX], Paper 14155–15 (2026).

**Code**: Can be provided upon request.

### Controller Software for Teledyne COSMOS camera

**Description**: This project involves the development of control software for the Teledyne COSMOS camera, using the [PICAM API and SDKs from Teledyne Princeton Instruments](https://www.teledynevisionsolutions.com/products/cosmos/). The software is responsible for managing the camera's settings, diagnostic monitoring, data acquisition, and communication with other systems through a server-client structure. The software is intended to be used for the [NTE visual imager](https://nbi.ku.dk/english/research/astrophysics/nte/).

**My Contribution**: I am the solo developer of this project, responsible for the design and implementation of the software.

**Code**: Can be provided upon request, but to limited extent, as some of the code is confidential due to observatory IT-security concerns.

### Data reduction pipeline for NTE imagers

**Description**: This project involves developing a flexible data reduction pipeline framework for supporting the [NTE imagers](https://nbi.ku.dk/english/research/astrophysics/nte/). The pipeline is designed to be strongly modular, allowing for easy integration of new cameras, with design allowing to modify the pipeline functionality on a by-camera basis without altering the driving core code.

**My Contribution**: I am the solo designer, developer and maintainer of this project. 

**Code**: <https://github.com/KostasValeckas/NTE_IMAGING_PIPELINES>

# Observing Contributions

### Nordic Optical Telescope (La Palma, Spain)

I have observed with the [Nordic Optical Telescope](https://www.not.iac.es/) (NOT) for roughly a 100 nights for several different programmes: 

- I held a position as a student support astronomer at the NOT for 1.5 years, where I both conducted observations in service mode for a [large array of science cases](https://ui.adsabs.harvard.edu/search/fq=%7B!type%3Daqp%20v%3D%24fq_database%7D&fq_database=(database%3Aastronomy%20OR%20database%3Aphysics)&q=%20author%3A%22Valeckas%22&sort=date%20desc%2C%20bibcode%20desc&p_=0) and supported visiting astronomers in their observations. I also trained new students and researchers on the telescope and its instruments. Furthermore, I have given telescope tours and presentations to visiting groups of students and researchers, as well as to the general public.
- I have conducted two observing runs as a visiting astronomer at the NOT, where I conducted observations on behalf of [NBI](https://nbi.ku.dk/english/).
- I have supported a 1-week summer school at the NOT, where I both functioned as a support astronomer and teaching assistant for the students - including hands-on tutorials and guidance on data reduction.
